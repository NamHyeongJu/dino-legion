# 공룡 군단 진격

공룡 방진이 야생 공룡 무리를 향해 진격하는 모바일 세로형 방치형(키우기) 웹 게임입니다. 서버 없는 싱글 플레이 게임이며 진행 상황은 각자의 브라우저(localStorage)에 저장됩니다.
`C:\Git\dino-nest-1\dino-nest-unity`의 공룡 시트(걷기·공격·쓰러짐 6프레임), 사룡 티라노사우루스, 종·특성·교배 규칙, 챕터 배경 팔레트, 합성 효과음, 폰트를 사용합니다.

## 실행

**바로 플레이: https://namhyeongju.github.io/dino-legion/** (GitHub Pages, 로그인·설치 필요 없음)

로컬에서는 `start.bat`을 더블클릭하면 로컬 파일 서버가 뜨고 브라우저가 `http://localhost:8081/`로 열립니다(포트가 사용 중이면 다음 번호).
서버는 파일만 전달합니다. 게임 로직은 모두 브라우저에서 돌아갑니다.
`index.html`을 직접 열어도 실행되지만, 브라우저 보안 정책 때문에 적 공룡의 붉은 눈 픽셀·폰트가 대체 방식으로 표시될 수 있습니다.

## 게임 방법

- 공룡 군단(6줄 × 5열, 최대 30마리)이 자동으로 진격하다 야생 공룡(흑백, 붉은 안광)을 만나면 돌격합니다.
- **레벨**: 등급 이름 없이 Lv 숫자만 씁니다. 색은 레벨마다 빨→주→노→초→파→남→보로 바뀌고 Lv.8부터 다시 빨강으로 돌아갑니다.
- **합성**: 같은 레벨 공룡 2마리 → 다음 레벨 1마리. 종은 상관없습니다. 부대 탭에서 공룡을 끌어 같은 레벨 공룡 위에 놓거나 **자동 합성**을 누르세요. 🔒 잠금한 공룡은 자동 합성에서 빠집니다.
- **역할**: 근접 공룡은 앞열, 브라키오는 2열에서 긴 목으로 공격합니다. 원거리(랩터, **불꽃 숨결** 특성 → 파이어볼)와 비행(프테라) 공룡은 줄을 바꿔서라도 항상 맨 후열로 이동해 안전하게 공격합니다.
- **교배 둥지** (부대 탭 아래): 6칸에 수컷·암컷을 한 쌍씩 넣습니다. 둥지에 들어간 공룡은 방진에서 빠집니다.
  알을 부화하면 6칸 중 하나가 무작위로 골라져 암수 한 쌍이 있으면 그 쌍의 새끼, 비어 있으면 야생 공룡이 태어납니다. 6쌍을 모두 채우면 고른 부모의 새끼만 태어납니다.
  - 아비 유전 20% · 어미 유전 20%: 한쪽의 종·색·특성을 그대로
  - 양친 유전 25%: 양쪽 특성을 모두 (최대 4개, 같은 특성은 35% 확률로 강화)
  - 혼합 유전 35%: 두 종의 고유 능력을 모두 가진 혼종, 색이 섞이고 양쪽에 있는 특성은 한 단계 강화, 한쪽 특성은 50%
  - 돌연변이 8%: 새 특성 + 새 색. 새끼 레벨은 최소 부모 평균 레벨의 절반
- **사룡 레이드**: 전투 화면의 해골 버튼. 90초 안에 사룡 티라노사우루스를 쓰러뜨리면 호박석·고기를 받고 레이드 레벨이 오릅니다. 입장권은 최대 3장, 30분마다 1장 충전됩니다.
- **강화 / 스킬 / 부화** 탭은 방진 돌격대와 같은 흐름입니다(고기로 강화, 호박석으로 스킬 소환).
- **옵션**(우상단 톱니): 효과음, 전투 속도 x1~x3, **치트: 재화 무한대**(고기·호박석·입장권 소모 없음), **진행도 초기화**(두 번 눌러 확인).

## 구조

- `index.html`, `css/style.css`: 화면 구성과 스타일
- `js/sheets.js`: 공룡 시트 프레임 표(자동 생성)
- `js/data.js`: 레벨 색, 종, 특성, 유전 확률, 적, 레이드, 스킬, 강화, 챕터, 퀘스트, 공식
- `js/engine.js`: 이미지 로딩, 프레임 렌더러(교배 색상 회전·흑백 붉은 눈·피격 플래시·안광), 합성 효과음
- `js/icons.js`: SVG 아이콘과 레벨 색 알
- `js/backdrop.js`: 챕터별 시차 배경
- `js/battle.js`: 전투(방진 배치, 종 고유 능력, 파이어볼·바람칼날, 프테라 급강하, 스킬, 레이드)
- `js/ui.js`, `js/main.js`: UI, 교배 둥지, 유전, 경제·저장·게임 루프
- `tools/build-assets.ps1`: Unity 시트(.bytes PNG)를 연결 성분으로 6프레임 분리·축소하고 눈 위치를 찾아 `assets/creatures`와 `js/sheets.js` 생성
- `tools/build-artifact.ps1`: 웹 공유(claude.ai Artifact)용 폴더 생성
